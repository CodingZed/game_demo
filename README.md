# 小小机长 · Little Sky Club

给 5 岁左右孩子玩的轻松 3D 客机游戏。选择波音 737、波音 747 或空客 A380，在云朵和海岛之间飞行，穿过彩色圆环收集星星。

## 在线玩

打开 **https://codingzed.github.io/game_demo/** 即可开始，不需要安装。

网站由 GitHub Pages 托管。推送到 `main` 后，GitHub Actions 会运行模型和碰撞测试、构建网页并自动发布；可在仓库的 Actions 页面查看发布进度。也可以手动运行 `Publish game to GitHub Pages` 工作流。

在线版的离线文件下载地址：https://codingzed.github.io/game_demo/little-sky-club.html 。另存为 `.html` 后可离线使用。

## 直接玩（不需要安装）

下载单文件版 `little-sky-club.html`，用 Chrome 或 Edge 打开即可。页面包含全部游戏代码、画面和声音，可以离线玩，无需启动服务器。若下载界面先显示源码，请使用「另存为」保存为 `.html` 文件，再用浏览器打开。

开发者可执行 `npm run build:standalone` 生成 `dist/little-sky-club.html`。普通的 `npm run build` 会重建 dist，因此需要单文件版时请再次执行该命令。

## 开发启动

需要 Node.js 20.19+ 或 22.12+（当前环境使用 Node.js 24）。

```bash
npm ci
npm run dev
```

在运行开发服务器的同一台电脑的浏览器中打开终端显示的地址。`127.0.0.1` 和 `localhost` 仅指当前电脑：云环境中启动的服务不能直接用这些地址从自己的电脑访问。支持现代 Chrome、Edge、Firefox 和 Safari，需要启用 WebGL。也可以在同一网络的平板上通过开发机器的局域网地址访问。

## 玩法

- 点击飞机卡片选择 737-800、747-8I 或 A380-800，拖动场景环绕观察；可直接切换「机头／侧面／俯视」。滚轮、双指捏合或「＋／−」按钮可缩放查看细节，「复位」恢复视角。
- 飞机持续向前飞。方向键或 WASD 控制上下左右；触屏使用屏幕上的大方向按钮。松开操作后保持当前高度和横向位置直飞，不会自动瞄准圆环。
- 按住「加速飞」加速，飞行场景获得焦点时也可按住空格。
- 起飞前选择难度：简单速度慢、障碍少、圆环判定宽松；普通速度接近简单的两倍、障碍更密、需要更准地穿圈；困难速度超过简单的三倍，障碍间距不到简单的四分之一，热气球还会上下左右移动。
- 困难模式需要跟随航线：连续漏过 3 个圆环会结束本次飞行（不会凭空坠机）；穿过任意圆环会清零漏圈次数。简单和普通模式漏圈不会结束。
- 穿过圆环获得星星。圆环和白云不是实体障碍；需要躲开橙色热气球。机身、机翼碰到热气球，或飞得太低碰到地面，都会触发卡通坠落。
- 坠落后可选择「再飞一次」，或返回更换飞机和难度；不会出现血腥画面。
- 「怎么玩」会暂停飞行；「换一架飞机」回到选择页面，再次出发时星星从零开始。
- 起飞后播放持续的风声和引擎声，加速时音色与强度随之变化。右上角可静音；「怎么玩」中可调飞行音量，默认 35%。暂停、坠落或回到机库时环境音停止。只保存声音开关与音量偏好，不收集个人资料。

飞机按真实机型的尺寸比例与典型外观特征程序建模，包括驾驶舱风挡、舱门、发动机进气道与排气口、机翼襟翼、客舱窗和起落架；采用 LITTLE SKY AIR 虚构涂装。737／747／A380 分别展示 6／18／22 个机轮，进入飞行后收起起落架；碰撞检测使用实际飞行模型。747-8I 包含加长上层舱、后掠翼尖和锯齿发动机尾缘。展示台提供投影与金属环境反射，拉近可查看细节。这些仍是简化模型，不是原厂精确 CAD，也不是专业飞行模拟器。所有图形和声音都在本地生成，无广告、登录、付费或外部素材请求。

## 验证与构建

```bash
npm test          # 飞行规则与模型测试
npm run test:e2e  # 桌面/触屏浏览器流程，需要 Chromium
npm run build    # 生成 dist/ 静态站点
npm run preview  # 本地检查构建产物
```

浏览器测试优先使用 `/usr/bin/chromium`。其他机器先运行 `npx playwright install chromium`。截图写入 `/tmp/little-sky-*.png`。

云环境中 npm 默认缓存不可写时使用 `npm ci --cache /workspace/.npm-cache`。在已有 `/workspace/game_demo` 仓库内工作即可，无需创建额外的 Git worktree。发布静态网站时部署 `dist/`；启动的开发服务器进程不会随环境快照保存。

Three.js 与内置 Helvetiker 字体的许可和署名保存在 `public/THIRD_PARTY_NOTICES.txt`，构建时会一起发布。
